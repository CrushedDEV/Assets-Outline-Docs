Easy Outline v1.0.0

¡Bienvenido a Easy Outline!

La forma más fácil de añadir contornos, brillos, rellenos y detección de bordes a tus juegos en el Universal Render Pipeline. Se configura sin código y, si lo necesitas, también desde código.

Unity 6 · URP 17 Unity 2022.3 LTS · URP 14 PC · Consolas · Móvil · WebGL Sin dependencias

¿Qué me ofrece Easy Outline?

  1. Fácil de usar: añade un componente a un objeto y listo. Todo se ve también en modo edición, sin pulsar Play.
  2. Cuatro estilos en uno: contornos finos (Fast), brillos suaves (Soft), contornos gruesos y uniformes (Wide) y rellenos con patrones.
  3. Ver a través de paredes: muestra objetos ocultos con contorno o relleno, al estilo rayos X.
  4. Estilo cómic o dibujado a mano: detección de bordes a pantalla completa, con líneas que “tiemblan” como en un dibujo.
  5. Pensado para el rendimiento: los objetos se agrupan por estilo y miles de objetos pueden contornearse sin componentes, por Rendering Layers.
  6. Funciona con todo: mallas animadas, hojas con recorte alfa, animación en el vertex shader, Shader Graph y GPU Resident Drawer.
  7. Estilos reutilizables: crea un perfil una vez (“Selección”, “Enemigo”, “Objeto recogible”…) y úsalo en todo el proyecto.

¿Qué tipo de efecto puedo añadir?

FAST · Contorno finoEl más barato. Ideal para muchos objetos y móviles. SOFT · BrilloHalo difuminado que brilla con Bloom. WIDE · Contorno gruesoGrosor exacto y uniforme, hasta 128 px. FILL · RellenoColor, rayas, puntos, damero o tu propia textura.

¿Por dónde empiezo?

InstalaciónAñade el paquete y configura los renderers con un clic. Tu primer contornoDe cero a contorno en menos de cinco minutos. La escena DemoDoce ejemplos listos para mirar y copiar.

¿Buscas algo concreto? Pulsa Ctrl K (o /) para buscar en toda la documentación.

Instalación

Añade el paquete al proyecto y deja que Easy Outline configure tus renderers. Son dos pasos.

Requisitos

  • Unity 6000.0 o superior con URP 17, o Unity 2022.3 LTS con URP 14.0.8 o superior.
  • El Universal Renderer (el Renderer 2D no tiene textura de profundidad).
  • En Unity 6, Render Graph activado (es la opción por defecto).

Paso 1 · Añade el paquete

  1. Abre Window › Package Manager.
  2. Elige My Assets, busca Easy Outline y pulsa Download y después Import.

Window › Package Manager › + › Add package from disk… y selecciona el archivo package.json del paquete.

Window › Package Manager › + › Add package from git URL… y pega la URL del repositorio. Si el paquete está dentro de un proyecto, añade la ruta al final:

https://github.com/USUARIO/REPOSITORIO.git?path=/Packages/com.easyoutline.urp

Copia la carpeta com.easyoutline.urp dentro de la carpeta Packages/ de tu proyecto. Unity la detecta al volver al Editor.

Paso 2 · Configura los renderers

Ejecuta Tools › Easy Outline › Set Up Renderers. Easy Outline busca los Universal Renderer Data de tu proyecto (el del pipeline por defecto y los de cada nivel de calidad) y les añade el renderer feature.

¡Listo! Ya puedes añadir tu primer contorno.

Si se te olvida este paso, el Inspector de Outline Object te avisa y muestra un botón Set Up. También puedes añadirlo a mano: selecciona tu renderer y pulsa Add Renderer Feature › Easy Outline.

Importar las muestras (opcional)

En Package Manager › Easy Outline › Samples encontrarás:

  • Demo: una sala con 12 expositores, uno por función. Ver La escena Demo.
  • Scripting Examples: scripts cortos que usan la API.

Ejecutar los tests (opcional)

Añade el paquete a testables en Packages/manifest.json y abre Window › General › Test Runner:

"testables": [ "com.easyoutline.urp" ]

Tu primer contorno

Esta guía es para tus primeros cinco minutos con Easy Outline. Al terminar tendrás un objeto contorneado y un estilo propio que podrás reutilizar.

Antes de empezar, asegúrate de haber hecho la instalación (sobre todo Tools › Easy Outline › Set Up Renderers).

Dos formas de trabajar, tú eliges. Puedes contornear objetos con un componente (lo más fácil) o sin componentes, marcándolos con una Rendering Layer (lo más eficiente para muchos objetos). Ninguna es “más avanzada”: usan el mismo sistema y puedes mezclarlas.

Paso 1 · Contornea un objeto

  1. Selecciona uno o varios objetos en la jerarquía.
  2. Haz clic derecho y elige Easy Outline › Add Outline To Selection (también en el menú GameObject).

Verás al momento un contorno naranja de 4 píxeles, también en la vista Scene. Es el perfil por defecto.

  1. En el Mesh Renderer del objeto, abre Rendering Layer Mask y activa una capa extra (por ejemplo la 8). Deja también Default.
  2. Selecciona tu Universal Renderer Data, despliega Easy Outline y pulsa + en Outline Layers.
  3. En la nueva capa, elige esa Rendering Layer y pulsa New junto a Profile.

Todos los objetos con esa Rendering Layer se contornean a la vez. Más detalles en Muchos objetos sin componentes.

Paso 2 · Crea tu propio estilo

El aspecto de un contorno lo define un Outline Profile: un asset con la técnica, el color, el grosor y el resto de ajustes.

  1. Crea el perfilEn el componente Outline Object, pulsa New junto a Profile y elige dónde guardarlo.
  2. Elige la técnicaFast (fino y barato), Soft (brillo), Wide (grueso y uniforme) o None (solo relleno). ¿Dudas? Mira ¿Qué técnica elijo?
  3. Ajusta color y grosorDespliega Profile Settings en el propio componente: los cambios se ven al instante.

Los perfiles son compartidos: si cambias uno, cambian todos los objetos que lo usan. Para variar un solo objeto usa los overrides del paso 3.

Paso 3 · Cambia un solo objeto

En Outline Object, activa la casilla de Color, Width u Opacity y ponle otro valor. Solo afecta a ese objeto; el resto sigue usando el perfil.

Paso 4 · Actívalo desde el juego

Añade using EasyOutline; y llama a OutlineObject.Add:

using EasyOutline;
using UnityEngine;

public class Pickup : MonoBehaviour
{
    public OutlineProfile highlight;

    void OnMouseEnter() => OutlineObject.Add(gameObject, highlight);
    void OnMouseExit()  => OutlineObject.RemoveAll(gameObject);
}

¿Qué está pasando? Add añade un componente Outline Object (o reutiliza el que ya tenga) con ese perfil, y RemoveAll lo quita. Para encender y apagar sin crear componentes, usa Show() y Hide().

Un contorno es un componente: actívalo o desactívalo como cualquier otro. Por ejemplo, desde un UnityEvent de un botón o de un trigger, arrastra el objeto y elige OutlineObject › enabled.

Para resaltar con el ratón sin escribir nada, usa el script OutlineHighlighter de la escena Demo. Ver Resaltar y seleccionar con el ratón.

Grupos: por qué conviene reutilizar perfiles

Los objetos que comparten perfil se dibujan juntos, como un grupo. El coste de las pasadas a pantalla completa depende del número de perfiles visibles, no del número de objetos.

Usa pocos perfiles bien elegidos (“Hover”, “Selección”, “Enemigo”…) en lugar de uno por objeto. Para variaciones puntuales, usa los overrides de Outline Object.

Contornos finos y baratos Fast

La técnica más rápida: sin texturas intermedias ni pasadas a pantalla completa. Perfecta para muchos objetos, móviles y contornos de pocos píxeles.

Cómo se hace

  1. Crea un perfilAssets › Create › Easy Outline › Outline Profile y pon Technique en Fast.
  2. Elige el espacio del grosorWidth Space: Screen Pixels (igual de grueso a cualquier distancia) o World Units (más fino al alejarse).
  3. AsígnaloA un Outline Object o a una Outline Layer.

Esquinas abiertas: normales suavizadas

Fast “infla” el objeto a lo largo de sus normales. En mallas con aristas duras (cubos, low-poly) las caras se separan y el contorno se abre en las esquinas. La solución son las normales suavizadas:

OpciónCuándo
Automático (por defecto)Outline Object las genera para mallas con Read/Write activado.
Tools › Easy Outline › Bake Smoothed Normals For SelectionMallas sin Read/Write, skinned o contorneadas por capas.
Assets › Easy Outline › Toggle Smoothed Normals On ImportQue se bakeen cada vez que se importa el modelo.

Las normales suavizadas se guardan en el canal UV3. Si tu malla usa UV3 para otra cosa, desactiva Smooth Normals en el perfil.

Limitaciones

  • No sigue la animación hecha en el vertex shader (sí el skinning y los blend shapes). Para eso usa Wide o Soft con Object Depth Pass.
  • Usa el bit 3 del stencil de la cámara.

Brillo y glow Soft

Un halo suave alrededor del objeto. Con color HDR, modo Additive y Bloom parece luz de neón.

Cómo se hace

  1. Técnica SoftEn el perfil, Technique = Soft.
  2. RadioWidth es el radio del brillo en píxeles (prueba entre 24 y 64).
  3. Modo aditivoBlend = Additive para sumar luz en lugar de pintar encima.
  4. Más intensidadSube Brightness por encima de 1 (o usa un color HDR) para que el Bloom lo recoja.

Ajustes útiles

AjusteEfecto
IntensityHace que el brillo llegue más lejos.
Hardness0 = degradado suave, 1 = borde duro.
ResolutionHalf o Quarter: casi idénticos para brillos y mucho más baratos.
Draw InsideDibuja el brillo también sobre el objeto.

¿No ves el Bloom? Comprueba que la cámara tiene Post Processing y HDR activos y que hay un Volume con Bloom.

En Soft el radio pertenece al perfil: el override de Width por objeto no tiene efecto.

Contornos gruesos Wide

Contornos de grosor exacto y uniforme (hasta 128 px) con esquinas redondeadas. Es la técnica por defecto.

Cómo se hace

  1. Técnica WideTechnique = Wide y elige Width en píxeles.
  2. SuavizadoSoftness controla el antialiasing del borde exterior (1 px va bien).
  3. Variaciones por objetoActiva los overrides de Color y Width en cada Outline Object.

Wide cuesta casi lo mismo con 1 objeto que con 100 del mismo perfil: el algoritmo trabaja sobre la pantalla, no sobre cada objeto.

Si la plataforma no puede renderizar texturas de coma flotante de dos canales (algunos WebGL y Android antiguos), Wide se dibuja automáticamente como Soft y el Inspector lo avisa.

Rellenos con patrones Fill

Pinta el interior de la silueta con un color, rayas, puntos, damero o tu propia textura. Ideal para estados (“seleccionado”, “bloqueado”) y para siluetas ocultas.

Cómo se hace

  1. Activa el rellenoEn cualquier perfil, despliega Surface Fill y marca Enabled. Funciona con cualquier técnica, incluso con None (solo relleno).
  2. Elige el patrónSolid, Stripes, Dots, Checker o Texture.
  3. AjustaScale (tamaño en píxeles), Angle, Thickness y Scroll para animarlo.
PatrónAjustes
SolidColor (el alfa es la opacidad).
Stripes · DotsScale, Angle, Thickness, Scroll.
CheckerScale, Angle, Scroll.
TextureTexture (con Wrap Mode: Repeat), Scale, Angle, Scroll. El alfa de la textura define el dibujo.

Use Object Color tiñe el relleno con el color de contorno de cada objeto: un solo perfil sirve para objetos de colores distintos.

Ver a través de paredes

Muestra aliados, objetivos o al jugador cuando quedan detrás de un obstáculo. Se controla con el ajuste Occlusion del perfil.

Los tres modos

OcclusionResultadoUso típico
Visible OnlySolo alrededor de la parte visible.Hover y selección normales
Always VisibleEl objeto entero, también a través de paredes.Aliados, objetivos
Occluded OnlySolo la parte oculta.Silueta del jugador tras una pared

Receta: silueta “detrás de la pared”

  1. Perfil de contornoWide, Occlusion = Always Visible, Priority = 1.
  2. Perfil de rellenoTechnique = None, Occlusion = Occluded Only, Surface Fill con rayas y un poco de Scroll.
  3. CombínalosAñade dos Outline Object al personaje, uno con cada perfil. Ver Combinar varios efectos.

Los objetos eliminados por Occlusion Culling no se dibujan, así que tampoco su contorno de rayos X. Si un objeto parpadea como “oculto”, sube Depth Bias en el feature.

Combinar varios efectos

Un objeto puede tener varios estilos a la vez: un brillo, un contorno encima y un relleno. Cada perfil aplica su efecto.

Cómo se hace

  1. Añade varios componentesPon dos o más Outline Object en el mismo GameObject, cada uno con su perfil.
  2. Ordena con PriorityLos perfiles con Priority mayor se dibujan encima.

Reglas de orden

  • Se dibuja por Priority ascendente; a igual prioridad, en el orden de la pila de capas y después en el de aparición de los componentes.
  • Dentro de un perfil, el relleno se dibuja antes que el contorno.
  • Un objeto puede estar en varias Outline Layers y tener componentes a la vez.

Muchos objetos sin componentes

Marca objetos con una Rendering Layer y todos se contornean con el mismo perfil. Es la opción más eficiente: compatible con el SRP Batcher, el GPU Resident Drawer y Entities Graphics.

Cómo se hace

  1. Pon nombre a la capa (opcional)Unity 6: Project Settings › Tags and Layers › Rendering Layers. Unity 2022.3: Project Settings › Graphics › URP Global Settings.
  2. Marca los objetosEn el Rendering Layer Mask de cada renderer, activa la capa. Desde código: OutlineRenderingLayers.Set(objeto, mascara, true).
  3. Añade una Outline LayerEn el feature (para todo el proyecto) o en un Outline Scene Settings (solo esa escena): elige la capa y un perfil.

Las Rendering Layers también controlan las Light Layers. Deja la capa Default activada en los objetos y usa capas extra para los contornos.

Para encender o apagar el contorno de un objeto concreto, cambia su Rendering Layer Mask. Para apagar todos a la vez, desactiva la Outline Layer (Enabled).

Resaltar y seleccionar con el ratón

El clásico de los juegos de estrategia y de los objetos interactivos: contorno al pasar el ratón y otro distinto al hacer clic.

Sin código: OutlineHighlighter

  1. Copia el scriptOutlineHighlighter está en la muestra Demo (Scripts/). Añádelo a cualquier objeto de la escena.
  2. Asigna dos perfilesHover Profile (por ejemplo, Wide blanco fino) y Selection Profile (por ejemplo, Wide de color con Always Visible).
  3. CollidersLos objetos seleccionables necesitan un collider y estar en Selectable Layers.

También expone eventos (On Hover Enter, On Hover Exit, On Selection Changed) para conectarlos desde el Inspector.

Con tu propio código

OutlineObject hover;

void UpdateHover(GameObject target)
{
    if (hover != null) hover.Hide();
    hover = target != null ? OutlineObject.Add(target, hoverProfile) : null;
    if (hover != null) hover.Show();
}

Dale al perfil de hover una Priority alta (por ejemplo 20) para que siempre quede por encima de otros contornos del objeto.

Hojas, vallas y recortes

Con materiales de alpha clipping (hojas, rejas, vallas), el contorno sigue la forma recortada, no el rectángulo de la malla.

Cómo se hace

  1. Activa Alpha CutoutEn el perfil, deja Alpha Cutout marcado (lo está por defecto).
  2. Usa un material con recorteUn material URP Lit/Unlit con Alpha Clipping activo. Easy Outline lee _BaseMap, _BaseColor, _Cutoff y _AlphaClip.

¿Shader Graph o un shader con otros nombres de propiedad? Cambia Geometry a Object Depth Pass: el recorte lo hace tu propio shader. Ver Objetos animados.

Objetos animados

Personajes con huesos, blend shapes y shaders que mueven vértices (viento, olas, gelatina): el contorno puede seguir la deformación.

Tipo de animaciónQué hacer
Skinning y blend shapesNada: funciona siempre, con todas las técnicas.
Vertex shader (viento, olas, Shader Graph)Perfil Soft, Wide o Fill con Geometry = Object Depth Pass.

¿Qué hace Object Depth Pass?

Dibuja la silueta con la pasada DepthOnly de tu propio shader, que aplica el mismo desplazamiento que ves en pantalla. Todos los shaders de URP y de Shader Graph la tienen.

Fast no puede seguir animación hecha en el vertex shader. Con Object Depth Pass no hay override de color ni de grosor por objeto: se usan los del perfil.

Detección de bordes estilo cómic

Un efecto a pantalla completa que dibuja líneas donde cambian la profundidad, las normales, el color o los objetos. No necesita componentes.

Cómo se hace

  1. ActívalaEn el feature, marca Edge Detection › Enabled.
  2. Crea un perfilPulsa New junto a Profile (o Create › Easy Outline › Edge Detection Profile).
  3. Elige las fuentesDepth (siluetas), Normals (pliegues), Color (cambios de luminancia) y Sections (entre objetos).
  4. Ajusta el trazoLine Color, Thickness y los umbrales de cada fuente.

Líneas solo en algunos objetos

Con Mask Mode eliges dónde aparecen las líneas usando Rendering Layers:

  • Include: solo sobre los objetos de Mask Layers (por ejemplo, solo personajes).
  • Exclude: en todas partes excepto sobre ellos (por ejemplo, sin líneas en la vegetación).

¿Demasiadas o pocas líneas?

  • Líneas falsas en suelos inclinados: activa Grazing Angle Correction o sube Depth Threshold.
  • Menos líneas interiores: sube Normal Threshold.
  • Líneas entre objetos que se tocan: activa Section Edges.

Por defecto se dibuja antes de los transparentes, así que el agua, el cristal y las partículas quedan por encima de las líneas. Puedes cambiarlo en Injection Point.

Estilo dibujado a mano

Convierte la detección de bordes en un trazo de lápiz: líneas irregulares que “tiemblan” como en la animación tradicional.

Cómo se hace

  1. DistorsiónActiva World-Space Distortion: Amount 1.5–3 px y Frequency 2–4.
  2. Grosor variableThickness Variation entre 0.4 y 0.7.
  3. “Boiling”Boil Frame Rate = 6–8: el ruido cambia varias veces por segundo, como un dibujo animado.
  4. AtenuaciónDistance Fade suaviza las líneas lejanas.

El ruido se calcula en espacio de mundo: las líneas “se pegan” a las superficies y no resbalan al mover la cámara.

Ajustes por escena

¿Un nivel con estilo cómic y otro sin líneas? Con Outline Scene Settings cada escena añade sus propias capas y su propia detección de bordes, sin tocar el renderer del proyecto.

Cómo se hace

  1. Añade el componenteCrea un GameObject vacío y añade Easy Outline › Outline Scene Settings.
  2. Capas propiasEn Layers, añade Outline Layers: se suman a las del feature mientras la escena está cargada.
  3. Bordes propiosMarca Override Edge Detection y elige si se dibujan y con qué perfil.

Como es un objeto de escena, los cambios que hagas en modo Play se deshacen al salir. Es la forma segura de cambiar ajustes en tiempo de ejecución.

Prioridad de la detección de bordes: Outline Camera > Outline Scene Settings (el último activado) > feature.

Animar desde código

El expositor 12 de la Demo (OutlineColorCycle) cambia el color y el grosor cada frame:

void Update()
{
    float hue = Mathf.Repeat(Time.time * 0.12f, 1f);
    outline.Color = Color.HSVToRGB(hue, 0.75f, 1f) * 1.4f;   // HDR: brilla con Bloom
    outline.Width = Mathf.Lerp(3f, 9f, 0.5f + 0.5f * Mathf.Sin(Time.time * 3f));
}

Solución de problemas

Los problemas más comunes y cómo arreglarlos en un minuto.

No se ve ningún contorno
  1. ¿Feature en el renderer? Ejecuta Tools › Easy Outline › Set Up Renderers. Cada nivel de calidad puede usar otro renderer.
  2. Unity 6 en modo de compatibilidad. Desactiva Compatibility Mode en Project Settings › Graphics › URP; la consola lo avisa.
  3. Tipo de cámara. Revisa Camera Types en el feature y el componente Outline Camera.
  4. Renderers. Solo MeshRenderer y SkinnedMeshRenderer.
  5. Opacidad 0 o Technique: None sin relleno.
  6. Capas: el renderer debe tener la Rendering Layer y la Outline Layer un perfil.
Funciona en el Editor pero no en la build

Mensaje Shader references are missing: pulsa Repair en el Inspector del feature o ejecuta Set Up Renderers. Antes de cada build se reparan automáticamente.

El contorno Fast tiene huecos en las esquinas

Faltan normales suavizadas. Ver Contornos finos (Fast).

Partes del contorno parpadean o desaparecen

Sube Depth Bias en el feature. Ocurre con superficies muy lejanas o por diferencias de precisión de profundidad.

El contorno no sigue la animación

Cambia Geometry a Object Depth Pass. Ver Objetos animados.

Las partes transparentes aparecen en la silueta

Activa Alpha Cutout en el perfil. Para shaders no estándar usa Object Depth Pass.

El brillo Soft es muy tenue

Width es el radio, Intensity alarga el brillo y Hardness endurece el borde. En modo Additive el resultado depende del fondo; con HDR y Bloom brilla más.

Hay líneas de más (o de menos) en la detección de bordes

Ver ¿Demasiadas o pocas líneas?.

Wide se ve como Soft

La plataforma no admite texturas de coma flotante de dos canales. El Inspector del perfil lo indica.

Rendimiento

Cinco reglas para que los contornos no cuesten casi nada.

  1. Pocos perfiles: las pasadas a pantalla completa se pagan por perfil visible, no por objeto.
  2. Rendering Layers para muchos objetos: se dibujan por lotes con el SRP Batcher y el GPU Resident Drawer.
  3. En móviles, Fast: y para Soft, resolución Quarter.
  4. Bordes ligeros: desactiva Normals y Grazing Angle Correction si no los necesitas (te ahorras la pasada depth-normals).
  5. Sin basura: Easy Outline no reserva memoria por frame y reutiliza sus texturas temporales entre perfiles.
TécnicaCoste por perfil (orientativo)
Fast2 draws por objeto, sin pasadas a pantalla completa.
Soft1 draw por objeto + blur H + blur V + composición.
Wide1 draw por objeto + semillas + log₂(grosor)+1 pasos + composición. 8 px a 1080p ≈ 6 pasadas ligeras.
Fill+1 pasada a pantalla completa.
Edges1 pasada con 5–9 lecturas por fuente activa.

Cómo funciona

Para curiosos y para quien quiera ampliar el paquete.

Estructura

com.easyoutline.urp/
├── Runtime/
│   ├── Components/     OutlineObject, OutlineCamera, OutlineSceneSettings
│   ├── Profiles/       OutlineProfile, EdgeDetectionProfile, enums
│   ├── Rendering/      Feature, pasadas, recorders, agrupado, formatos
│   └── Utilities/      Normales suavizadas, Rendering Layers
├── Shaders/            Object, Composite, EdgeDetection
├── Editor/             Inspectores, setup de renderers, bakeado, menús
├── Tests/Editor/       Tests EditMode
└── Samples~/           Demo y Scripting

Un frame

AddRenderPasses (por cámara)
 ├─ OutlinePass.Setup → agrupa capas + componentes por perfil y ordena por prioridad
 └─ EdgeDetectionPass.Setup → elige perfil y solicita depth / normals / opaque

Record(IOutlineRecorder) — escrito una vez para los dos backends
 ├─ por grupo: Fast · máscara · Fill · Soft (blur) · Wide (jump flood) · composición
 └─ vista de depuración opcional

IOutlineRecorder tiene dos implementaciones: Render Graph (Unity 6) y Execute (Unity 2022.3, con un pool de texturas reutilizadas entre grupos). El código de dibujo es común.

Añadir una técnica

  1. Añade el valor a OutlineTechnique, sus campos a OutlineProfile y su sección al Inspector.
  2. Si necesita la máscara, devuélvelo en RequiresMask.
  3. Añade las pasadas al shader y sus índices en ShaderIDs.cs.
  4. Escribe RecordX(IOutlineRecorder, …) en OutlinePass. Funciona en ambos backends.
  5. Añade un test en RenderingTests.
